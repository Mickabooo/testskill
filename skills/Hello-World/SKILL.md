When a user types "Hello World" or "hello world":

1. Render HELLO WORLD as a large ASCII-art banner
2. Use only standard ASCII characters, such as letters, spaces, underscores, slashes, and vertical bars.
3. Put the banner in a fenced code block to preserve spacing.
4. Return only ASCII-art banner with no explanation
